# Bambu Studio 多账号图形化切换器

## Context

已验证的事实（前两轮探索）：
- Bambu Studio 只认 `%APPDATA%\BambuStudio` 目录名，登录态完全自包含在目录内，重命名即切换账号
- 现有两个配置：`BambuStudio`（个人 <个人UID>，当前活动）、`BambuStudio-work`（工作 <工作UID>）
- 每个配置目录的**当前登录 uid** 可从 `BambuStudio.conf` 的 `"preset_folder"` 字段可靠读取
- 昵称/头像**本地无法直接提取**（token 加密存储且不解密；WebView2 缓存多用户混杂；公网接口有 Cloudflare 防护）

本轮需求：图形化界面 = 自动发现账号 + 显示头像 + 点击切换 + 添加账号；头像/用户名通过登录后从 Bambu 获取。

## 技术选型

- **PowerShell 5.1 + WPF**（Win11 自带，零安装；本机无可用 Python/tkinter）
- **WebView2 WPF 控件**：运行时系统已有（Bambu Studio 依赖它），但 .NET 控件 DLL 需首次运行时自动下载 NuGet 包 `Microsoft.Web.WebView2`（~2MB，解压到工具目录 `webview2-lib\` 后 Add-Type 加载）
- ps1 保存为 **UTF-8 with BOM**；bat 启动器 GBK+CRLF

## 交付文件（`<用户目录>\Desktop\hdmi测试\bambu-switcher\`）

```
bambu-switcher\
├── BambuAccountSwitcher.ps1    主程序（WPF GUI，UTF-8 BOM）
├── Bambu账号切换器.bat          启动器（powershell -STA -ExecutionPolicy Bypass）
└── webview2-lib\               首次运行自动下载的 WebView2 DLL
```

旧的 `switch-bambu-account.bat` 保留作命令行备用。

## 数据模型

**自动发现**：扫描 `%APPDATA%\BambuStudio*`：
- `BambuStudio` = 当前活动配置；`BambuStudio-<slug>` = 停放配置
- 当前登录 uid 从 `<目录>\BambuStudio.conf` 的 `preset_folder` 读取（比 user\ 子目录更准确，能区分历史残留）

**元数据** `<目录>\_switcher\profile.json`（随目录走）：
```json
{ "slug": "work", "displayName": "工作账号", "uid": "<工作UID>",
  "nickname": "<同步的真实昵称>", "avatar": "avatar.jpg" }
```
头像缓存在 `_switcher\avatar.*`；无头像时 WPF 画首字符圆形占位图。

## GUI 布局

```
┌─ Bambu Studio 账号切换器 ─────────────────┐
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│ │  ○头像    │ │  ○头像    │ │    ＋     │ │
│ │ 个人账号  │ │ 工作账号  │ │ 添加账号  │ │
│ │ ID:2039… │ │ ID:1418… │ │          │ │
│ │ ●活动中   │ │ [切换]    │ │          │ │
│ │ [同步资料] │ │ [同步资料]│ │          │ │
```

卡片：64px 圆形头像、显示名（同步到真实昵称后显示真实昵称）、uid、活动徽章；卡片按钮：切换（非活动卡）、同步资料、编辑（改显示名/手动选头像图）。

## 核心逻辑

**切换账号**：检查 `bambu-studio` 进程（运行中→弹窗拒绝）→ `BambuStudio` ↔ `BambuStudio-<slug>` 互换（经三步重命名，失败回滚）→ 勾选则启动 `C:\Program Files\Bambu Studio\bambu-studio.exe` → 刷新。

**添加账号**：进程检查 → 当前 `BambuStudio` 改名为停放名 → 启动 Bambu Studio 并引导"登录新账号后完全退出，再回来点完成" → 点完成：检测到新 `BambuStudio\BambuStudio.conf` 的 `preset_folder` → 分配 slug（`account3`…）→ 立即触发"同步资料"流程 → 保持活动。取消则删除新目录、恢复原活动目录。

**同步资料（获取真实昵称+头像）**：
1. 弹出内嵌 WebView2 窗口，用户数据目录设为该配置的 `_switcher\webview-data\`（每账号会话隔离，下次免登）
2. 打开 `https://makerworld.com.cn/zh`（国内站），用户登录自己的 Bambu 账号
3. 工具轮询/监听导航，登录成功后在 webview 内 `fetch('/api/v1/design-user-service/my/profile')`（真实浏览器环境过 Cloudflare，返回 JSON 含 `name`、`avatarUrl` 类字段——实施时按实际返回字段名适配）
4. 下载头像到 `_switcher\avatar.*`，昵称写入 `profile.json`，关窗刷新卡片
5. 用户也可跳过同步，仅手动设置显示名/头像

**首次运行迁移**：`BambuStudio`（含 account.marker）→ 显示名"个人账号" slug=personal；`BambuStudio-work` → "工作账号" slug=work；uid 自动读取。

## 实施要点

- WebView2 DLL 下载：`https://www.nuget.org/api/v2/package/Microsoft.Web.WebView2`（nupkg=zip，取 `lib/net45/Microsoft.Web.WebView2.Wpf.dll` 与 `Microsoft.Web.WebView2.Core.dll`，另需 `runtimes/win-x64/native/WebView2Loader.dll`）；下载失败时功能降级（隐藏"同步资料"按钮，其余正常）
- 所有重命名前校验目录存在/目标名空闲，任一步失败回滚
- XAML 内嵌 here-string；WebView2 控件在代码中创建（避免 XAML 程序集映射问题）

## 验证

1. 启动 GUI → 列出 2 张卡片，活动徽章在个人账号，uid 正确
2. 点"同步资料"→ webview 登录 → 卡片显示真实昵称+头像 → 重启工具仍在
3. 切换工作账号 → Bambu Studio 自动启动且免登录为 <工作UID> → 切回
4. App 运行中点切换 → 弹窗拒绝
5. 添加账号 → 到登录界面后取消 → 目录恢复原状
6. 断网/下载失败 → 同步按钮降级，切换功能不受影响
